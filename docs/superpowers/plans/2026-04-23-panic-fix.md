# Panic Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eliminate the "panic in a function that cannot unwind" abort when the time-tracking-nvim plugin loads in Neovim by (a) making config loading non-panicking in `time-tracking-cli` and (b) adding `catch_unwind` guards at every `extern "C"` boundary in the plugin.

**Architecture:** Add `try_get_no_args() -> anyhow::Result<&'static Config>` to `time-tracking-cli` backed by a separate `OnceLock<String>` for the error case. Use a `path` override in `time-tracking-nvim/Cargo.toml` during development. Wrap the plugin entry point and every `Function::from_fn` callback in `std::panic::catch_unwind(AssertUnwindSafe(...))` so no panic can escape through an `extern "C"` frame.

**Tech Stack:** Rust, nvim-oxi, anyhow, `std::panic::catch_unwind`


Then, inside `impl Config`, add this new private function immediately before `fn init`:

```rust
fn try_init(use_args: bool) -> anyhow::Result<&'static Config> {
    if let Some(config) = CONFIG.get() {
        return Ok(config);
    }
    if let Some(err) = CONFIG_LOAD_ERR.get() {
        return Err(anyhow::anyhow!("{}", err));
    }
    match Config::load(use_args) {
        Ok(config) => {
            let _ = CONFIG.set(config);
            Ok(CONFIG.get().unwrap())
        }
        Err(e) => {
            let err_str = e.to_string();
            let _ = CONFIG_LOAD_ERR.set(err_str);
            Err(e)
        }
    }
}
```

### Task 3: Add `catch_unwind` helpers and update the plugin entry point

**Files:**

- [ ] **Step 1: Add `panic_message` helper and `catch_nvim` helper**

At the top of `src/lib.rs`, after the existing `use` imports, add:

```rust

```

Then add these two free functions (not inside `impl`) anywhere before `time_tracking_nvim`:

```rust
fn panic_message(payload: Box<dyn std::any::Any + Send>) -> String {
    if let Some(s) = payload.downcast_ref::<String>() {
        s.clone()
    } else if let Some(s) = payload.downcast_ref::<&str>() {
        s.to_string()
    } else {
        "time-tracking-nvim: unknown panic".to_owned()
    }
}

fn catch_nvim_panic<F>(f: F) -> Result<()>
where
    F: FnOnce() -> Result<()>,
{
    panic::catch_unwind(AssertUnwindSafe(f))
        .map_err(|payload| {
            let msg = panic_message(payload);
            api::err_writeln(&format!("[time-tracking-nvim] panic: {}", msg));
            nvim_oxi::Error::Other(msg)
        })
        .and_then(|r| r)
}
```

- [ ] **Step 2: Wrap the plugin entry point**

Replace the existing `time_tracking_nvim` function:

```rust
#[nvim_oxi::plugin]

    let config = Config::get_no_args();
    time_tracking_with_config(config)
}
```

with:

```rust
#[nvim_oxi::plugin]
fn time_tracking_nvim() -> Result<Dictionary> {
    panic::catch_unwind(AssertUnwindSafe(|| {
        let config = Config::try_get_no_args()
            .map_err(|e| nvim_oxi::Error::Other(e.to_string()))?;
        time_tracking_with_config(config)
    }))
    .map_err(|payload| nvim_oxi::Error::Other(panic_message(payload)))
    .and_then(|r| r)
}
```
